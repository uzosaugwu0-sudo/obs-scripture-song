# Run-order (service plan) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Plan tab (first and default) where a volunteer builds a named service plan of songs and Bible readings, runs it with a deliberate **Next item** action, and edits it while it runs.

**Architecture:** A new `src/plan/` module (pure model, cursor logic, file/local storage) plus `src/dock/plan-tab.js`. Plans are one JSON file each in `plans/` inside the library folder, with a localStorage mirror. Next item calls new `loadSong` / `loadReading` methods on the existing Songs and Scripture tabs, which preview the content in the live bar; the live path (`session`, `live-bar`, overlay) is not rewritten. A generic `createRecordFolder` is extracted from `songs/folder.js` so songs and plans share the same atomic-write, safe-filename and collision code.

**Tech Stack:** Vanilla JS modules bundled by esbuild into classic IIFE scripts, Vitest (unit), Playwright (browser, static server on :4173, needs `npm run build`).

**Spec:** `docs/superpowers/specs/2026-10-21-run-order-design.md`

## Global Constraints

- OBS 28+ over `file:///`: classic IIFE bundle via esbuild, no ES-module script tags, no fetch of local files.
- Model and store functions return new copies; never mutate a plan, item list or song record.
- Reuse the library's folder access, safe filenames (`safeFilename`), collision handling and dirty tracking (`dirty` set so edits made while disconnected win on reconnect).
- The overlay is unchanged: do not touch `src/overlay/` or `src/css/overlay.css`.
- The nested `obs-scripture-song/obs-scripture-song/` copy is git-ignored and must not be touched.
- `dist/` is rebuilt (`npm run build`) and committed together with any change under `src/`.
- Plan file shape: `{ "v": 1, "id": "p_...", "name": "...", "items": [ { "id": "i_...", "type": "song", "songId": "..." }, { "id": "i_...", "type": "reading", "ref": "John 3:16-17", "translation": "KJV" } ] }`. Item `type` is an open set; unknown types are preserved and shown as "Unsupported item".
- Plan files live in `plans/<safe-name>.json` inside the library folder; plan localStorage keys are `obs-stage-plans` and `obs-stage-last-plan`.
- Keys: `PageDown` = Next item, `PageUp` = previous item. Existing shortcuts (arrows, Space, Escape) must keep working.
- Baseline before this plan: 254 Vitest tests, 67 Playwright specs, coverage thresholds 80% lines/functions (actual ~92.7%).
- Files are written with CRLF on disk by git (`core.autocrlf=true`); that is expected.

## Review Focus

Failure modes the spec implies that no single task's happy path exercises; each has a test in the named task.

1. A song deleted from the library while it is in a plan: row shows "Song missing", Next item skips it, the plan file is not rewritten (Tasks 2, 5, 6).
2. Next item or a row tap while the Songs editor holds unsaved text: refused with a message, nothing is lost (Task 6).
3. Next item pressed twice quickly, or while a verse lookup is in flight: no skipped or duplicated item, a "still loading" message (Task 6).
4. Folder lost or write denied mid-session: plan edits stay in the browser copy, no exception, and are written to the folder after Reconnect (Task 4).
5. A hand-edited, foreign or newer-version `.json` in `plans/`, and two plans with the same name: listed as unreadable and never overwritten; duplicate names become "Name (2)"; an unsafe name like `Sun 10/26: AM` is saved as a safe filename with the real name kept inside (Tasks 3, 4).

```js
import { uid as defaultUid } from '../songs/model.js';

export const PLAN_VERSION = 1;
export const DEFAULT_PLAN_NAME = 'Untitled plan';

const cleanName = (name) => (name || '').trim() || DEFAULT_PLAN_NAME;
const isItem = (i) => !!i && typeof i === 'object' && typeof i.id === 'string' && typeof i.type === 'string';

export function isPlanRecord(x) {
  return !!x && typeof x === 'object' && typeof x.id === 'string' && typeof x.name === 'string'
    && (x.v === undefined || (Number.isInteger(x.v) && x.v <= PLAN_VERSION))
    && Array.isArray(x.items) && x.items.every(isItem);
}

export function toPlanRecord(x) {
  return { v: PLAN_VERSION, id: x.id, name: x.name, items: x.items.map((i) => ({ ...i })) };
}

export function createPlan(name = DEFAULT_PLAN_NAME, uid = defaultUid) {
  return { v: PLAN_VERSION, id: 'p_' + uid(), name: cleanName(name), items: [] };
}

export const songItem = (songId, uid = defaultUid) => ({ id: 'i_' + uid(), type: 'song', songId });
export const readingItem = (ref, translation, uid = defaultUid) => ({ id: 'i_' + uid(), type: 'reading', ref, translation });

export function addItem(plan, item, afterId = null) {
  const at = afterId === null ? -1 : plan.items.findIndex((i) => i.id === afterId);
  const index = at === -1 ? plan.items.length : at + 1;
  return { ...plan, items: [...plan.items.slice(0, index), item, ...plan.items.slice(index)] };
}

export function moveItemTo(plan, id, toIndex) {
  const from = plan.items.findIndex((i) => i.id === id);
  if (from === -1) return plan;
  const to = Math.max(0, Math.min(plan.items.length - 1, toIndex));
  if (to === from) return plan;
  const rest = plan.items.filter((i) => i.id !== id);
  return { ...plan, items: [...rest.slice(0, to), plan.items[from], ...rest.slice(to)] };
}

export function moveItem(plan, id, delta) {
  const from = plan.items.findIndex((i) => i.id === id);
  return from === -1 ? plan : moveItemTo(plan, id, from + delta);
}

export function removeItem(plan, id) {
  return plan.items.some((i) => i.id === id) ? { ...plan, items: plan.items.filter((i) => i.id !== id) } : plan;
}

export const renamePlan = (plan, name) => ({ ...plan, name: cleanName(name) });

/** A name no other plan uses (case-insensitive): "Name", then "Name (2)", "Name (3)"... */
export function uniqueName(plans, name, exceptId = null) {
  const base = cleanName(name);
  const taken = new Set(plans.filter((p) => p.id !== exceptId).map((p) => p.name.toLowerCase()));
  if (!taken.has(base.toLowerCase())) return base;
  let n = 2;
  while (taken.has((base + ' (' + n + ')').toLowerCase())) n += 1;
  return base + ' (' + n + ')';
}
```

```js
export function itemStatus(item, library) {
  if (item.type === 'song') return library.get(item.songId) ? 'ok' : 'missing';
  if (item.type === 'reading') return typeof item.ref === 'string' && item.ref.trim() ? 'ok' : 'unsupported';
  return 'unsupported';
}

export function itemTitle(item, library) {
  const status = itemStatus(item, library);
  if (item.type === 'song') return status === 'ok' ? (library.get(item.songId).title || 'Untitled') : 'Song missing';
  if (item.type === 'reading' && status === 'ok') return item.ref;
  return 'Unsupported item';
}

export const indexOfItem = (plan, id) => (id === null ? -1 : plan.items.findIndex((i) => i.id === id));

export function nextLoadable(plan, currentId, library) {
  for (let i = indexOfItem(plan, currentId) + 1; i < plan.items.length; i += 1) {
    if (itemStatus(plan.items[i], library) === 'ok') return plan.items[i];
  }
  return null;
}

export function prevLoadable(plan, currentId, library) {
  for (let i = indexOfItem(plan, currentId) - 1; i >= 0; i -= 1) {
    if (itemStatus(plan.items[i], library) === 'ok') return plan.items[i];
  }
  return null;
}

/** What is current once `removedId` leaves the plan. Pass the plan as it is BEFORE the removal. */
export function currentAfterRemove(plan, currentId, removedId) {
  if (currentId !== removedId) return currentId;
  const at = indexOfItem(plan, removedId);
  return at > 0 ? plan.items[at - 1].id : null;
}

/** The one-line "3 of 6 · Next: John 3:16" shown in the live bar. */
export function planSummary(plan, currentId, library) {
  const total = plan.items.length;
  if (!total) return null;
  const at = indexOfItem(plan, currentId);
  const next = nextLoadable(plan, currentId, library);
  const where = at === -1 ? total + (total === 1 ? ' item' : ' items') : (at + 1) + ' of ' + total;
  return where + ' \u00b7 ' + (next ? 'Next: ' + itemTitle(next, library) : 'End of plan');
}
```

```js
const err = (name) => Object.assign(new Error(name), { name });

export function createFakeDir(initial = {}) {
  const files = new Map(Object.entries(initial));
  const dir = {
    name: 'songs',
    files,
    subdirs: new Map(),
    denied: false,
    guard() { if (dir.denied) throw err('NotAllowedError'); },
    async getDirectoryHandle(name, { create = false } = {}) {
      dir.guard();
      if (!dir.subdirs.has(name)) {
        if (!create) throw err('NotFoundError');
        dir.subdirs.set(name, createFakeDir());
      }
      return dir.subdirs.get(name);
    },
    async getFileHandle(name, { create = false } = {}) {
      dir.guard();
      if (!files.has(name)) {
        if (!create) throw err('NotFoundError');
        files.set(name, '');
      }
      return {
        kind: 'file',
        name,
        async getFile() { return { text: async () => files.get(name) }; },
        async createWritable() {
          dir.guard();
          let buffer = '';
          return {
            async write(text) { buffer += text; },
            async close() { files.set(name, buffer); },
            async abort() {},
          };
        },
      };
    },
    async removeEntry(name) {
      dir.guard();
      if (!files.has(name)) throw err('NotFoundError');
      files.delete(name);
    },
    async *values() {
      dir.guard();
      for (const name of [...files.keys()]) {
        yield { kind: 'file', name, getFile: async () => ({ text: async () => files.get(name) }) };
      }
      for (const name of dir.subdirs.keys()) yield { kind: 'directory', name };
    },
  };
  return dir;
}
```

```js
const BACKSLASH = String.fromCharCode(92);

export function safeFilename(title, fallback = 'song') {
  return (title || 'untitled')
    .replace(/[<>:"/|?*\x00-\x1f]/g, '_').split(BACKSLASH).join('_').replace(/\s+/g, '_')
    .replace(/_+/g, '_').slice(0, 80).replace(/^_+|_+$/g, '') || fallback;
}

/**
 * One JSON file per record in a user-chosen directory. createWritable() writes
 * to a swap file and only replaces the original on close(), so a crash
 * mid-write leaves the previous version intact; we abort() on failure.
 * Files that are not records are reported by list() and never overwritten.
 */
export function createRecordFolder(dirHandle, { isRecord, toRecord, nameOf, label = 'song' }) {
  const fileOf   = new Map();   // record id to file name
  const occupied = new Set();   // lower-cased names of files that are not ours

  async function writeText(name, text) {
    const handle   = await dirHandle.getFileHandle(name, { create: true });
    const writable = await handle.createWritable();
    try {
      await writable.write(text);
      await writable.close();
    } catch (err) {
      try { await writable.abort(); } catch { /* stream already closed; surface the original error */ }
      throw err;
    }
  }

  async function removeFile(name) {
    try {
      await dirHandle.removeEntry(name);
    } catch (err) {
      if (err.name !== 'NotFoundError') throw err;
    }
  }

  function unusedName(base, id) {
    const taken = new Set(occupied);
    for (const [otherId, name] of fileOf) if (otherId !== id) taken.add(name.toLowerCase());
    let name = `${base}.json`;
    let n = 2;
    while (taken.has(name.toLowerCase())) { name = `${base} (${n}).json`; n += 1; }
    return name;
  }

  async function list() {
    const records = [];
    const errors  = [];
    fileOf.clear();
    occupied.clear();
    for await (const entry of dirHandle.values()) {
      if (entry.kind !== 'file' || !entry.name.toLowerCase().endsWith('.json')) continue;
      try {
        const file = await entry.getFile();
        const data = JSON.parse(await file.text());
        if (!isRecord(data)) throw new Error(`Not a ${label} file`);
        records.push(toRecord(data));
        fileOf.set(data.id, entry.name);
      } catch (err) {
        occupied.add(entry.name.toLowerCase());
        errors.push({ file: entry.name, message: err.message });
      }
    }
    return { records, errors };
  }

  async function write(record) {
    const clean = toRecord(record);
    const previous = fileOf.get(clean.id);
    const name = unusedName(safeFilename(nameOf(clean), label), clean.id);
    await writeText(name, JSON.stringify(clean, null, 2));
    fileOf.set(clean.id, name);
    if (previous && previous !== name) await removeFile(previous);
  }

  async function remove(id) {
    const name = fileOf.get(id);
    if (!name) return;
    await removeFile(name);
    fileOf.delete(id);
  }

  return { name: dirHandle.name, list, write, remove, writeText };
}
```

```js
import { isPlanRecord, toPlanRecord } from './model.js';

export const PLANS_KEY     = 'obs-stage-plans';
export const LAST_PLAN_KEY = 'obs-stage-last-plan';

/** Plans kept in the browser: the plan list when no folder is chosen, and a safety copy beside the folder. */
export function createLocalPlanStore(storage, onError = () => {}) {
  function load() {
    try {
      const raw = storage?.getItem(PLANS_KEY);
      if (!raw) return [];
      const parsed = JSON.parse(raw);
      return Array.isArray(parsed) ? parsed.filter(isPlanRecord).map(toPlanRecord) : [];
    } catch (err) {
      onError(err);
      return [];
    }
  }

  function save(plans) {
    try {
      storage?.setItem(PLANS_KEY, JSON.stringify(plans));
    } catch (err) {
      onError(err);
    }
  }

  function loadLastId() {
    try {
      return storage?.getItem(LAST_PLAN_KEY) || null;
    } catch (err) {
      onError(err);
      return null;
    }
  }

  function saveLastId(id) {
    try {
      if (id) storage?.setItem(LAST_PLAN_KEY, id);
      else storage?.removeItem(LAST_PLAN_KEY);
    } catch (err) {
      onError(err);
    }
  }

  return { load, save, loadLastId, saveLastId };
}
```

```js
import { uid as defaultUid } from '../songs/model.js';
import { toPlanRecord, uniqueName } from './model.js';
import { createPlanFolder } from './folder.js';

/**
 * The plans the dock can open. Plans live in memory as immutable records; every
 * change goes to plans/ in the library folder when it is connected and writable
 * (canWrite), and always to the browser copy. A failed write keeps the plan and
 * marks it dirty, so it wins over the folder copy when the folder is attached again.
 */
export function createPlanStore({ local, onError = () => {}, canWrite = () => true, uid = defaultUid }) {
  let plans = local.load();
  let folder = null;
  let unreadable = [];
  const dirty = new Set();

  async function persist({ write = [], remove = [] } = {}) {
    if (!folder || !canWrite()) {
      write.forEach((p) => dirty.add(p.id));
      local.save(plans);
      return;
    }
    try {
      for (const plan of write) await folder.write(plan);
      for (const id of remove) await folder.remove(id);
    } catch (err) {
      onError(err);
      write.forEach((p) => dirty.add(p.id));
    }
    local.save(plans);
  }

  const get = (id) => plans.find((p) => p.id === id) || null;

  async function save(input) {
    const record = toPlanRecord({ ...input, id: input.id || 'p_' + uid(), name: uniqueName(plans, input.name, input.id) });
    plans = plans.some((p) => p.id === record.id)
      ? plans.map((p) => (p.id === record.id ? record : p))
      : [...plans, record];
    await persist({ write: [record] });
    return record;
  }

  async function remove(id) {
    if (!get(id)) return;
    plans = plans.filter((p) => p.id !== id);
    dirty.delete(id);
    await persist({ remove: [id] });
  }

  async function duplicate(id) {
    const source = get(id);
    if (!source) return null;
    return save({
      ...source,
      id: 'p_' + uid(),
      name: source.name + ' (copy)',
      items: source.items.map((i) => ({ ...i, id: 'i_' + uid() })),
    });
  }

  /** The folder is truth; plans only in memory, and plans edited while it was unavailable, are written into it. */
  async function attach(dirHandle) {
    const newFolder = await createPlanFolder(dirHandle);
    const { records, errors } = await newFolder.list();
    const edited = new Set(dirty);
    dirty.clear();
    const inFolder = new Set(records.map((p) => p.id));
    const carried = plans.filter((p) => edited.has(p.id) || !inFolder.has(p.id));
    folder = newFolder;
    unreadable = errors;
    plans = [...records.filter((p) => !edited.has(p.id)), ...carried];
    await persist({ write: carried });
    return { loaded: records.length, carried: carried.length, errors };
  }

  function detach() {
    folder = null;
    unreadable = [];
    local.save(plans);
  }

  return {
    list: () => plans, get, save, remove, duplicate, attach, detach,
    unreadable: () => unreadable,
    lastId: () => local.loadLastId(),
    setLastId: (id) => local.saveLastId(id),
  };
}
```

```js
import { $ } from './util.js';
import { createPlan, addItem, songItem, readingItem, renamePlan, DEFAULT_PLAN_NAME } from '../plan/model.js';
import { itemStatus, itemTitle, indexOfItem, planSummary } from '../plan/cursor.js';

const TYPE_ICON = { song: '♫', reading: '✝' };
const BANNER_TEXT = {
  local: 'Plans are saved in this browser only. Open Songs, Library tools and choose a library folder to keep them as files.',
  'folder-lost': 'Lost access to the library folder. Plans are safe in this browser. Open Songs, Library tools and choose Reconnect.',
};

function make(tag, className, text) {
  const el = document.createElement(tag);
  if (className) el.className = className;
  if (text !== undefined) el.textContent = text;
  return el;
}

/**
 * The Plan tab: a named list of songs and readings. It only decides what to
 * load; what is on air is still decided by Show and Hide in the live bar.
 */
export function initPlanTab({ session, store, library, tabs, setStatus, showView, refresh, report }) {
  const select = $('plan-select'), listEl = $('plan-list'), banner = $('plan-banner'),
        unreadableEl = $('plan-unreadable'), btnMenu = $('btn-plan-menu'), menu = $('plan-menu'),
        picker = $('picker-banner'), pickerText = $('picker-text');

  let plan = store.get(store.lastId()) || store.list()[0] || createPlan();
  let currentId = null;     // the item most recently loaded from the plan
  let picking = null;       // 'songs' | 'scripture' while the operator chooses something to add
  let queue = Promise.resolve();

  /** Plan changes run one after another, so two quick edits never overwrite each other. */
  const enqueue = (job) => { queue = queue.then(job).catch(report); return queue; };

  async function commit(next) {
    plan = next;
    // A brand-new empty plan stays a draft until it gets an item or a name.
    if (store.get(plan.id) || plan.items.length || plan.name !== DEFAULT_PLAN_NAME) plan = await store.save(plan);
    store.setLastId(plan.id);
    render();
  }
  const edit = (change) => enqueue(() => commit(change(plan)));

  const openPlan = (next) => enqueue(async () => {
    plan = next;
    currentId = null;
    store.setLastId(plan.id);
    render();
  });

  // ── Rendering ─────────────────────────────────────────────────────────────

  function renderSelect() {
    const known = store.list();
    const entries = known.some((p) => p.id === plan.id) ? known : [...known, plan];
    select.replaceChildren(...entries.slice().sort((a, b) => a.name.localeCompare(b.name)).map((p) => {
      const option = make('option', '', p.name);
      option.value = p.id;
      return option;
    }));
    select.value = plan.id;
  }

  function renderBanner() {
    const mode = library.mode();
    banner.classList.toggle('hidden', mode === 'folder');
    banner.classList.toggle('is-lost', mode === 'folder-lost');
    banner.textContent = BANNER_TEXT[mode] || '';
    const bad = store.unreadable();
    unreadableEl.classList.toggle('hidden', !bad.length);
    unreadableEl.textContent = bad.map((e) => 'Unreadable plan file: ' + e.file).join(' · ');
    picker.classList.toggle('hidden', !picking);
    pickerText.textContent = 'Adding to ' + plan.name;
  }

  function statusText(item, index, currentIndex) {
    const status = itemStatus(item, library);
    if (status !== 'ok') return status;
    if (index < currentIndex) return 'done';
    if (item.type === 'song') {
      const count = library.get(item.songId).slides.length;
      return count + (count === 1 ? ' slide' : ' slides');
    }
    return item.translation || 'reading';
  }

  function renderRow(item, index, currentIndex) {
    const status = itemStatus(item, library);
    const li = make('li', 'plan-item' + (item.id === currentId ? ' cur' : '') + (index < currentIndex ? ' done' : '') + (status !== 'ok' ? ' missing' : ''));
    li.dataset.id = item.id;
    const grip = make('span', 'plan-grip', '≡');
    grip.setAttribute('aria-hidden', 'true');
    const icon = make('span', 'plan-icon', TYPE_ICON[item.type] || '?');
    const title = make('span', 'plan-title', itemTitle(item, library));
    const state = make('span', 'plan-status', statusText(item, index, currentIndex));
    li.append(grip, icon, title, state);
    return li;
  }

  function renderRows() {
    if (!plan.items.length) {
      listEl.replaceChildren(make('li', 'plan-empty faint', 'Nothing planned yet. Use + Song or + Verse, or press + Plan on a song or verse.'));
      return;
    }
    const currentIndex = indexOfItem(plan, currentId);
    listEl.replaceChildren(...plan.items.map((item, index) => renderRow(item, index, currentIndex)));
  }

  function render() {
    renderSelect();
    renderBanner();
    renderRows();
    refresh();
  }

  // ── Adding ────────────────────────────────────────────────────────────────

  function finishAdd(keepOpen, label) {
    setStatus('Added ' + label + ' to ' + plan.name + '.', 'success');
    if (picking && !keepOpen) {
      picking = null;
      showView('plan');
    }
  }

  async function addSong(songId, keepOpen = false) {
    await edit((p) => addItem(p, songItem(songId), currentId));
    const song = library.get(songId);
    finishAdd(keepOpen, song ? song.title : 'song');
  }

  async function addReading(ref, translation, keepOpen = false) {
    await edit((p) => addItem(p, readingItem(ref, translation), currentId));
    finishAdd(keepOpen, ref);
  }

  function startPicking(target) {
    picking = target;
    showView(target);
    if (target === 'scripture' && tabs.scripture) tabs.scripture.focus();
  }

  // ── Plan menu ─────────────────────────────────────────────────────────────

  function setMenu(open) {
    menu.classList.toggle('hidden', !open);
    btnMenu.setAttribute('aria-expanded', String(open));
  }

  btnMenu.addEventListener('click', (e) => { e.stopPropagation(); setMenu(menu.classList.contains('hidden')); });
  menu.addEventListener('click', () => setMenu(false));
  document.addEventListener('click', (e) => { if (!menu.contains(e.target) && e.target !== btnMenu) setMenu(false); });
  // Capture phase: while the menu is open, Escape only closes it and never reaches the Hide shortcut.
  document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape' && !menu.classList.contains('hidden')) { setMenu(false); e.stopPropagation(); }
  }, true);

  $('plan-new').addEventListener('click', () => {
    const name = prompt('Name for the new plan:', '');
    if (name === null) return;
    enqueue(async () => { currentId = null; await commit(createPlan(name)); });
  });

  $('plan-rename').addEventListener('click', () => {
    const name = prompt('Rename this plan:', plan.name);
    if (name === null) return;
    edit((p) => renamePlan(p, name));
  });
```
